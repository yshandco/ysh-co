# YSH & CO. — Premium Creative Advertising & Product Visuals Studio

> **Beyond The Ordinary. Into The Iconic.**  
> Website: [yshandco.com](https://yshandco.com)

A production-quality website for **YSH & CO.**, a premium creative advertising and product visuals studio creating powerful commercial advertising visuals, product photography, and brand experiences that turn attention into brand impact.

---

## 🎨 Visual Identity

- **Deep Black:** `#080808`
- **Champagne Gold:** `#D8AE4A`
- **Pure White:** `#FFFFFF`
- **Neutral Grey:** Secondary & body typography
- **Original Monogram Logo:** Precision gold circular emblem

---

## ✨ Features

- **Cinematic Hero:** Dynamic ambient studio lighting, subtle dust bokeh particle canvas, and bold editorial typography.
- **Interactive Portfolio Gallery:**
  - High-resolution commercial photoshoot concepts for **Luxury Perfume**, **Skincare**, **Luxury Watch**, **Food & Beverage**, **Fashion & Accessories**, and **Lifestyle**.
  - Category filtering tabs (`ALL`, `LUXURY PERFUME`, `SKINCARE`, `LUXURY WATCH`, `FOOD & BEVERAGE`, `FASHION & ACCESSORIES`, `LIFESTYLE`).
  - Interactive Project Detail Modal/Lightbox with art direction notes, lighting/camera specs, and deliverables breakdown.
- **Services Section:** Comprehensive overview of studio offerings (Static Advertising Creatives, Product Photography & Visuals, Social Media Creatives, Campaign Concepts, Creative Direction).
- **About YSH & CO.:** Brand mission, purpose, and visual storytelling philosophy.
- **Our Process:** Four-stage delivery framework (`01 DISCOVER` → `02 CONCEPT` → `03 CREATE` → `04 DELIVER`).
- **Functional Project Enquiry Form:** Complete client onboarding form with real backend delivery via FormSubmit.
- **Custom Interactive Elements:** Magnetic luxury cursor, sticky blur navigation, smooth scroll, and responsive mobile menu.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React + custom inline brand SVGs

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yshandco/ysh-co.git
cd ysh-co

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
